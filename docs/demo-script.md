# Loom walkthrough script (5–10 minutes)

1. Introduce the safety goal and enter a real sample trip such as Denver to Salt Lake City.
2. Select a future departure and a checkpoint interval.
3. Explain that the backend geocodes locations and requests only actual Mapbox alternatives.
4. Compare distance, duration, arrival, severe miles, and weather coverage.
5. Select a route and inspect map geometry and colored checkpoint markers.
6. Open checkpoint details to show wind, rain, snow, arrival time, and final risk.
7. Explain the load-sensitive wind rules and why missing data is shown as Unknown.
8. Explain the deterministic recommendation order and No Travel safety gate.
9. Show the automated risk tests and the API/architecture documentation.
10. Mention that deployment needs Mapbox environment variables; no external API result is claimed until configured.
